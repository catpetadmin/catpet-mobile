CatPet มือถือ

สร้างน้องจากรูป แล้วส่งขึ้นออนไลน์ให้คอมดึงไปใช้

เชื่อมกับเซิร์ฟเวอร์ CatPet

เปิดลิงก์ "หน้ามือถือ" จาก CatPet ในคอม (บัญชี > ใช้บนมือถือ) แล้วจะตั้งค่าให้เอง หรือใส่เองด้านล่าง (Project URL + anon key เท่านั้น)

ล็อกอิน

ใช้อีเมลเดียวกับใน CatPet ที่คอม น้องที่สร้างจะขึ้นเป็นน้องออนไลน์ของบัญชีนี้

ตั้งค่า AI ยังไม่มี key

ใช้ OpenAI API key ของคุณเอง เก็บไว้ในมือถือเครื่องนี้เท่านั้น (ไม่ส่งไปที่อื่นนอกจาก api.openai.com) แนะนำให้สร้าง project key แยกสำหรับมือถือ และตั้งงบรายเดือนต่ำในหน้า OpenAI

ก่อนเริ่ม

ขั้น "สร้างภาพ Master" "สร้าง sprite sheet" และ "แก้ท่า" จะส่งรูปและข้อความ prompt ไปที่ OpenAI (api.openai.com ต่างประเทศ) โดยใช้ key และเครดิตของคุณ รูปอยู่ในหน้าเว็บนี้ระหว่างทำงาน ไม่ได้บันทึกไว้ในมือถือ น้องที่ส่งขึ้นออนไลน์ เพื่อนของคุณจะเห็น

ควรใช้รูปตุ๊กตา สัตว์เลี้ยง หรือภาพวาด ถ้าเป็นรูปคน ต้องได้รับอนุญาตจากเจ้าของรูปก่อน
